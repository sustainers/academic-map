# University of Zagreb

- *OSPO*: No

## General Description

The University of Zagreb (UNIZG) does not have an Open Source Program Office, but supports open source through policy and individual centres:

- **Open Science Policy:** adopted in 2024, it [encourages researchers](https://interoperable-europe.ec.europa.eu/collection/open-source-observatory-osor/news/open-source-service-open-science) to store original program code in open repositories to support reproducibility.
- **Centre for Software Development:** at the Faculty of Organization and Informatics, it [takes part in open source projects](https://www.foi.unizg.hr/en/about-us/departments/czrpp) and supports students and researchers working on them.
- **University Computing Centre (SRCE):** provides [open science support](https://www.srce.unizg.hr/en/open-science-support).
