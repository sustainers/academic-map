# Stony Brook University

- *OSPO*: No

## General Description

Stony Brook University (SBU) does not have an Open Source Program Office. Open source work happens in individual departments and labs, including:

- **Department of Biomedical Informatics:** maintains a [GitHub organization](https://bmi.stonybrookmedicine.edu/SBUBMIGithub) for open source projects led by faculty, many supported by state and national grants. The department has been a [Google Summer of Code](https://bmi.stonybrookmedicine.edu/gsoc) mentoring organization since 2015.
- **Computer Vision Lab (CVLab):** publishes its research code on [GitHub](https://github.com/cvlab-stonybrook), including work on document unwarping, crowd counting, and scanpath prediction.
